# Bike Sales Analysis

## 📌 Project Overview

**Bike Sales Analysis** is a data analysis and dashboard project created to understand bike sales performance and identify important sales trends.

The project analyzes sales data based on factors such as **customer demographics, bike models, age groups, income, location, and purchasing behavior**. The analysis helps identify which customer segments and products contribute most to bike sales.

## 🎯 Objectives

- Analyze overall bike sales performance.
- Identify customer groups with higher purchase rates.
- Analyze sales based on age and gender.
- Understand the impact of income on bike purchases.
- Compare bike purchases across different regions.
- Identify important sales trends and patterns.
- Create a dashboard to present the analysis clearly.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Interactive Dashboard

## 📊 Key Analysis

The project includes analysis of:

- Bike Purchases
- Customer Age Groups
- Gender-wise Purchases
- Income-wise Purchases
- Regional Sales
- Commute Distance
- Customer Demographics
- Purchase Trends

## 📈 Dashboard

An interactive Excel dashboard was created to visualize the key sales metrics and customer purchasing patterns. It helps users quickly understand which customer segments and factors are associated with higher bike purchases.

## 💡 Project Outcome

This project demonstrates how Excel can be used to clean, analyze, visualize, and interpret sales data. The insights can help businesses better understand their customers, identify target segments, and make data-driven decisions to improve bike sales.
